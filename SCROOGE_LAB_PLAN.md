# SCROOGE LAB — research-only fork

This branch is reserved for offline research and reproducibility. It is not a live or practice trading deployment.

## Guardrails
- Never run `python main.py --live` for this project.
- Do not add `OANDA_API_TOKEN`, `OANDA_ACCOUNT_ID`, or any API credentials to GitHub Secrets or tracked files.
- Run only deterministic unit tests and explicitly offline research scripts in CI. Unit tests passing **does not** validate profitability.
- Do not enable inherited or upstream automated trading workflows.
- Treat the README's upstream live equity figures as **someone else's record**, not results generated by SCROOGE LAB.
- Historical-price corpora are not present in the Git fork. Reproduction requires sourcing, verifying and date-splitting the archive separately.
- The original project's live trading routines remain intact in the inherited source tree for code comparison only; they are **not authorized** for execution.

## Stage 1 — software baseline
1. Check out this branch and run `python -m pytest -q -p no:randomly tests`.
2. Record pass/fail counts and any environmental dependencies.
3. Inspect replay entry logic and exits for point-in-time and intra-bar leakage.
4. Fix data + testing protocol before running strategy comparisons.

## Stage 2 — independently reproducible backtest
- Pin original commit SHA and historical dataset manifest/checksums.
- Chronological train / validation / untouched test split with post-2026-07-03 leak-clean corpora only.
- Include executable bid/ask, trading costs, spread, slippage, holding/rollover costs.
- Report total trades, net return, win rate, payoff ratio, profit factor, max drawdown, per-pair distribution, and sensitivity tests.
- Compare parent-only vs grid/pop-ups separately. No live execution.

## Stage 3 — forward paper only
- Introduce a *separate*, order-free signal collector after Stage 2 tests validate.
- Do not reuse the original live `main.py` runner for paper trading.
